# PRPT_MNGE_CLAUDE — 부동산 통합 익스포저 관리 시스템

주택담보대출·투자부동산·주택연금의 부동산을 지역(시군구·읍면동) 단위로 자동 분류·집계하고, 가격지수와 연계해 지도에서 관리하는 브라우저 단독 실행형 시스템입니다. (1안 상세기획서 1단계 범위)

> 저장소의 모든 주소·금액·가격지수 데이터는 **가상 데이터**입니다. 실데이터는 커밋하지 마세요.

## 바로 쓰기
| 파일 | 용도 |
|---|---|
| `부동산통합관리시스템_내부망.html` | **내부망 반입용 단일 파일.** 라이브러리·행정구역 경계 내장, 서버·Python 불필요, 외부 자동 요청 0건 |
| `web/부동산통합관리시스템.html` | 웹 버전(라이브러리 CDN 로드, Claude 아티팩트 게시용) |
| `샘플데이터/부동산통합_로우데이터_양식.xlsx` | 원천별 로우데이터 표준 양식 |
| `샘플데이터/샘플_가상_202608.xlsx`, `샘플_가상_202609.xlsx` | 시연용 가상 데이터(202609에는 점검 시연용 오류 3건 포함) |

html 파일을 Chrome/Edge로 열고 **엑셀 불러오기**로 양식 파일을 넣으면 됩니다. 처음 열면 가상 샘플이 보입니다.

## 기능
- **지도**: 검색, 원천·유형·지역·리스크 필터, 개별 물건/지역 집계(가격지수·조기경보·비중 색칠), 읍면동 세분화, 현 지도 영역 검색
- **집중도·비교**: 상위 10개 지역 비중, 지역 HHI, 하락지역 익스포저, LTV 분포, 기준월 대비 증감
- **스트레스**: 주택·상업용 하락률·처분비용률 슬라이더, 전국/상위/지정 지역 시나리오
- **조기경보**: 관찰·주의·경계 등급(기준값 설정 가능)
- **점검·주소정제**: 필수항목·자릿수·배분비율·좌표 점검, 완료 게이트(G1~G5) 수치, 미매칭 주소 확정 → 매핑 사전
- **데이터·내보내기**: 기준월 스냅샷, 원천 대사, 분기보고 패키지(xlsx), 통합테이블(csv), 보고 코멘트 초안

## 빌드
```bash
python3 tools/build.py
```
`src/app.html`을 고친 뒤 실행하면 위 두 html이 다시 만들어집니다(표준 라이브러리만 사용).

- `tools/prep_geo.py`: 행정동 경계(vuski/admdongkor)·시군구 경계(통계청 SGIS 2018, 공공누리 1유형) → `geo_data.json`
- `tools/make_sample_v2.py`: 가상 샘플 생성(시제품 폴더의 `regions.py`, `샘플_로우데이터_가상.xlsx` 필요)
- `tools/lib/`: Leaflet 1.9.4, Leaflet.markercluster 1.5.3, topojson 3.0.2, SheetJS 0.18.5

## 유의사항
- 브라우저 주소정제는 시군구 분류까지 보장합니다. 법정동코드 10자리·건별 좌표는 행안부 주소DB 매칭 단계에서 채웁니다.
- 조기경보 기준값·스트레스 하락률은 예시값입니다.
- 불러온 데이터는 해당 PC 브라우저 저장소에만 남습니다.
